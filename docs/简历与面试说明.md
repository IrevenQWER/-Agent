# 学生学情分析 Agent：简历与面试说明

## 30 秒项目介绍

这是一个面向教育培训机构一线教师的单学生学情分析 Agent。教师用自然语言指定学生、学科和周期后，系统通过成绩、作业、考勤和课堂反馈构建可复现的学习画像，再从经过审核的历史干预案例中做混合检索，生成带业务记录 ID 和案例 ID 的结构化报告。报告必须经过程序化事实校验和教师确认才能完成。

业务语境参考湖南未来教育科技集团有限公司的多校区教育培训流程。演示仓库使用脱敏模拟数据和独立实现代码，不包含真实学生数据或公司专有资产。

## 推荐简历表述

**基于多源学情数据与案例增强生成的学生学情分析 Agent**

- 使用 LangGraph 构建单 Agent 显式状态机，编排请求解析、学生消歧、权限校验、多源数据查询、指标计算、学习画像、案例检索、报告生成、事实校验和教师确认，并覆盖澄清、数据不足、越权、校验重试等分支；
- 将学生档案、成绩、作业、考勤和课堂反馈封装为 Learning Data MCP 工具，通过统一 `LearningDataGateway` 实现 SQLite/MCP 双适配，教师身份由受信任执行上下文注入并在每次查询执行对象级校验；
- 设计脱敏历史案例 Schema，以 Chroma 持久向量索引、BM25、年级/学科/趋势过滤和画像规则重排实现案例 RAG，支持相似原因、干预前后指标和案例 ID 引用；
- 将成绩趋势、作业提交率、订正率、到课率和数据完整度改为确定性计算，通过 Pydantic Schema 及数值、趋势、引用、隐私和不当标签校验抑制幻觉；
- 实现 FastAPI 后台任务、SQLite 任务/报告持久化、教师修改后再校验、证据查询、确认后导出、审计事件、JSON 日志、Gradio 工作台和 Docker Compose；
- 建立单元、集成、真实 MCP、API E2E 和离线 RAG 评测；固定 5 条人工标注案例集上实测 Recall@3=1.00、MRR=1.00，并在描述指标时明确数据集规模。

## 架构决策问答

### 为什么是单 Agent，而不是多 Agent？

任务目标单一，所有步骤共享同一份学生、周期、指标和证据状态。LangGraph 节点已经能提供清晰的职责分离、条件路由和重试边界；拆成多个自治 Agent 会增加通信、状态一致性、延迟和调试成本。MCP Server 是外部数据能力，不是 Agent。

### 为什么使用 MCP？为什么不是所有工具都用 MCP？

成绩、作业、考勤等能力来自外部教务域，存在跨应用复用和独立演进价值，因此适合作为 Learning Data MCP。指标计算、画像、事实校验与当前工作流状态强耦合，而且要求低延迟和完全确定性，所以保留为进程内工具。

### 这个 RAG 与教研知识库有什么区别？

它不是开放式教研资料问答。检索对象是经过审核、脱敏且包含干预前后观察指标的历史学情案例；查询来自程序生成的结构化学习画像，并先按年级、学科和成绩趋势过滤。案例只能增强建议，不能改写当前学生事实。

### 如何降低幻觉？

核心数字全部由程序计算；模型只接收结构化事实和允许引用 ID；报告必须符合 Pydantic Schema；生成后校验数值文本、趋势、证据存在性、案例支持范围、隐私模式和不当标签；校验失败有限重试；最终仍需教师确认。

### 权限相同，为什么仍然需要权限系统？

一线教师和班主任不区分角色功能，但每位教师能看的学生集合不同。这不是 RBAC 菜单权限，而是教师—学生对象级数据范围控制。学生消歧也只能在已授权名册中执行，避免通过候选列表泄露其他学生。

## 演示顺序

1. 用 `S1001 + 2026年3月 + 数学` 发起正常任务；
2. 展示成绩、作业、考勤和课堂反馈记录 ID；
3. 展示结构化指标和 Chroma/BM25 检索的案例引用；
4. 展示报告校验结果和 `awaiting_confirmation` 状态；
5. 删除证据或修改数字，展示确认被拒绝；
6. 恢复报告并确认，展示任务进入 `completed` 和 Markdown 导出；
7. 用缺失时间范围的请求展示主动澄清；
8. 用 `T1001` 请求 `S2001` 展示越权对象不被披露；
9. 切换 `APP_LEARNING_DATA_BACKEND=mcp_stdio` 展示真实 MCP 子进程链路。

## 不应夸大的内容

- 当前 Demo 使用 FastAPI BackgroundTasks，不应写成已落地 Celery/Redis；
- 默认身份请求头只模拟可信网关注入，不应表述为完整企业 SSO；
- 默认 Embedding 为确定性哈希向量，不应写成已部署 BGE-M3；
- 5 条评测集只能说明回归集效果，不能代表大规模线上准确率；
- SQLite 和 stdio MCP 适用于演示，不等于多租户生产部署；
- 不应声称使用了公司真实学生数据、公司源代码或专有接口。
